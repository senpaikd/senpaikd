## About me

I'm Kent, a full-stack developer from Southern Leyte, Philippines, currently working as a programmer at **Southern Leyte State University**.

I build practical systems using **Laravel, PHP, Python, and MySQL**, and I've been spending more time on **AI-assisted tools**, **document workflows**, and **research-related systems**.

I like building software that solves real problems — not just things that look good in a demo.

## Featured projects

### [Documind](https://github.com/senpaikd/documind)
AI-assisted document tool for working with files and extracting useful answers from their contents.  
**Stack:** Next.js, TypeScript  
[Live Demo](https://documind-bay-kappa.vercel.app/)

### [Helpdesk Ticketing](https://github.com/senpaikd/Helpdesk-ticketing)
A Laravel-based ticketing system for managing support requests, conversations, and staff workflows.  
**Stack:** Laravel, PHP, MySQL

### [Oras DTR](https://github.com/senpaikd/DTR-PROJ)
A daily time record and attendance system for managing employee logs and access.  
**Stack:** PHP, Laravel

### [Portfolio](https://github.com/senpaikd/porfolio_sia)
A personal portfolio project with a backend for managing content and showcasing work.  
**Stack:** Laravel, Filament, Tailwind CSS
